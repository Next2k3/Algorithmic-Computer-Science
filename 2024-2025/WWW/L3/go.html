Gra Go

Implementacja klasycznej gry planszowej Go z interfejsem graficznym. Aplikacja umożliwia rozgrywkę dwóch graczy na planszy o różnych rozmiarach. Projekt został opracowany w ramach przedmiotu „Programowanie obiektowe", prowadzonego na Politechnice Wrocławskiej w roku akademickim 2023/2024. Implementacja wykorzystuje język Java oraz bibliotekę JavaFX do tworzenia interfejsu graficznego. 


private void updateBreathsForGroup(StoneGroup stoneGroup){
    stoneGroup.setBreaths(0);
    for(Stone stone : stoneGroup.getStones()) {
        updateBreaths(stoneGroup, stone.getRow(), stone.getCol());
    }
    if(stoneGroup.getBreaths() == 0){
        for(Stone stone : stoneGroup.getStones()){
            if(stone.getStoneGroup().getStones().size() == 1) {
                if (stone.getStoneColor() == StoneColor.WHITE) {
                    blockedStonesWhite = stoneGroup.getStones();
                } else {
                    blockedStonesBlack = stoneGroup.getStones();
                }
            }
        removeStone(stone.getRow(), stone.getCol());
        }
    }
}
